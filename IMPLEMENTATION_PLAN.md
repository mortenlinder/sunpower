# Implementeringsplan

1. Etabler en afhængighedsfri PHP 8.2-kerne med lokal autoloader og miljøkonfiguration.
2. Implementér sikker Modbus RTU, profilvalidering, simulator, telemetri og kommando-kø.
3. Implementér pris/tarif/optimizer, API, dansk dashboard, PWA og wallboard.
4. Lever Apache-, systemd-, installations- og commissioning-materiale.
5. Kør den lokale test-runner og statiske kontroller; fysisk Growatt-test udestår.

Ingen ekstern PHP-pakkehåndtering indgår. Apache er den eneste understøttede webserver.
